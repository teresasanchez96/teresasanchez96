## 📂 Mis proyectos

### 🐾 [Mascotas y Vacunas](https://github.com/teresasanchez96/Mascotas-Vacunas)

Aplicación Android desarrollada como proyecto de **Desarrollo de Aplicaciones Multiplataforma (DAM)** para gestionar la información de mascotas y sus vacunas.

El proyecto permite registrar, consultar, modificar y eliminar mascotas, así como gestionar las vacunas asociadas a cada una.

**Tecnologías:** Kotlin · Jetpack Compose · Android Studio · Spring Boot · Java · MariaDB · Retrofit · Room · Hilt
